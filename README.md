Project Description

This project focuses on predicting the type of offensive play an NFL team will attempt during a regular-season game. Using play-level data from multiple seasons, we build supervised learning models to classify each offensive play as one of several well-defined categories.

Data

Our dataset comes from:
https://www.kaggle.com/datasets/keonim/nfl-game-scores-dataset-2017-2023

We use all regular-season NFL games from 2017 through 2025.

Target Variable

We define a categorical target variable called PlayAttempt, which represents the offensive play an NFL team attempted. This label is generated by parsing the string fields Description and PlayOutcome. Each play is either removed or classified as one of the following:

run — Any designed run by the quarterback or running back

short_pass — A pass attempt traveling < X yards in the air

long_pass — A pass attempt traveling ≥ X yards in the air

field_goal — A field-goal attempt

punt — A punt

spike — A clock-stopping spike

Additional Classification Rules

A run that results in a fumble remains classified as a run.

A reception followed by a receiver fumble is classified as short_pass or long_pass based on the depth of the catch.

An interception is classified as short_pass or long_pass depending on where the interception occurred.

Removed Plays

We exclude:

sacks

kickoffs

non-offensive field goals or special-teams actions

QB fumbles where intent cannot be determined

penalties

timeouts

abnormal or malformed play descriptions

This ensures that only meaningful offensive play calls are included.

Features

Down – The current down (1–4).

YdsTo1stDown – Yards needed for a first down.

YdsToEndzone – Yards remaining to the end zone.

team_run_pct – Probability that the team calls a run.

team_short_pass_pct – Probability that the team calls a short pass.

team_long_pass_pct – Probability that the team calls a long pass.

Calculation of Team Play-Calling Percentage Features

The three percentage features reflect a team’s offensive tendencies and are calculated using only Run + Short_Pass + Long_Pass plays. Special-teams plays (punts, field goals), spikes, and abnormal plays are excluded.

To prevent data leakage, each game’s percentages are based only on past information:

1. First 3 Games of a Season

Uses the team’s entire previous season (e.g., Week 1–3 of 2023 uses all 2022 games).
This approximates realistic pre-season expectations.

2. Games 4 and Beyond

Uses a rolling window of all prior games in the same season (e.g., Week 5 uses Weeks 1–4).
This captures evolving strategy while keeping temporal consistency.

3. 2017 Season

Since no previous season exists in the dataset, we use league-wide historical averages:

Run: 44.37%

Short Pass: 50.78%

Long Pass: 4.84%

Consistency Within Games

All plays in a given game receive the same tendency values because these values are derived before the game begins, ensuring no look-ahead bias.
